# RonDev SJDM Business Request + Tracking Portal (Demo)

A lightweight Next.js + Tailwind demo for **SJDM businesses** (clinics, salons, repair/services, coops, local shops).
Customers submit a request, receive a **tracking code**, and check status anytime. Staff view requests in an **admin dashboard**.

✅ Demo flow: **Request → Tracking Code → Track → Admin Dashboard**

---

## Features (Demo Scope)

**Customer-facing**
- Landing page
- Submit request form (no customer login)
- Tracking page (enter tracking code)

**Staff-facing**
- Admin request list (demo gate via query key)
- Status display (default: pending)
- Copy tracking code

> Note: For production, add authentication + access control/RLS. This demo keeps setup minimal.
